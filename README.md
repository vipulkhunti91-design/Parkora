# Parkora 🚗

Parkora is a modern mobile-first web application for finding, booking, and managing parking spots. Built with React 19, React Router v7, Tailwind CSS v4, and Vite.

## Features

- **Authentication:** Mock OTP-based login and social auth flows.
- **Find Parking:** Search and explore nearby parking spots.
- **Booking Flow:** Select vehicle type, duration, and time slots.
- **Payment & History:** Checkout screen and history of past bookings.
- **Responsive Shell:** Confined "Phone Shell" UI wrapping for a native app feel on desktop browsers.

## Tech Stack

- **Framework:** React 19
- **Routing:** React Router v7
- **Styling:** Tailwind CSS v4
- **Bundler:** Vite v8

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v22+ recommended) and npm installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd parkora
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

### Running the App

To start the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### Building for Production

To create a production build of the app:

```bash
npm run build
```

The compiled assets will be output to the `dist` directory.
